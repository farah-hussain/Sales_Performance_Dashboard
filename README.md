# Sales_Performance_Dashboard
This is my Excel project where I created a visualization for retail store sales data. The goal is to turn raw data into an easy-to-understand dashboard to quickly check sales and profits.

## What is included in this project?
Built using Microsoft Excel.
Used charts, graphs, and slicers to filter and view data easily.
Highlighted main KPIs like Total Sales, Total Profit, Quantity of Orders and Total Orders.

## Key Insights from Dashboard:
* Business Growth: The Superstore generated strong total sales and net profit.
* Product Performance: Technology is the highest-selling category, while a few sub-categories like tables and bookcases show Losses.
* Discount Impact: Sales peak heavily during specific Year due to strategic discounts and high-volume VIP customers.
*

## Dashboard Features:
Interactive Slicers: You can click buttons (category, Segment and Years) to view data Dynamical .
Visual Charts: Region-wise sales distribution, product category breakdown, and Monthly sales trends.

## How to view this project?
1. Download the Sample - Superstore.xlsx file from this repository.
2. Open the file in Microsoft Excel to explore the charts and slicers.
